# 网站测试说明

`npm test` 一键运行（vitest，node 环境，秒级出结果，不起浏览器）。

## 覆盖范围（tests/smoke.test.mjs）

| 层 | 检什么 | 防什么事故 |
|---|---|---|
| 源码层 | 8 个关键页面存在且非空（中/英/404/作品动态路由） | AI 删错文件、页面改空 |
| 源码层 | 17 个作品 frontmatter 字段合法：category 枚举、level 枚举、必填字段齐全 | AI 改坏内容集合导致构建/页面崩 |
| 源码层 | 诚实标注 attribution 字段存在（原创/参考还原/教程跟做等）。来源字段 attribution_source 不强制：跟练作品已在片尾标注来源（2026-09-10 拍板） | 上线内容漏标性质 |
| 产物层 | dist 存在关键页面；首页/关于/联系/404/英文页的内链无死链 | 改路径后链接悄悄断掉 |
| 兼容层 | dist CSS 无区间写法媒体查询（width<= / width>=） | 百度 T7 老内核手机端样式整块失效（与 scripts/check-mq.mjs 双保险） |

产物层/兼容层在 dist 不存在时自动跳过（skipIf），不会误报。

## 没覆盖到的（后续可选）

- **视觉回归**：页面截图对比（puppeteer-core 已在 devDependencies，scripts/mobile-shots.mjs 可改造）
- **移动端断言**：媒体查询"存在性"未验证（只查了"非法写法"），可用 puppeteer 跑视口快照
- **英文页死链**：目前死链检查只扫中英首页/关于/联系/404，作品详情页内链未扫
- **表单提交**：contact 页如有表单交互未测
